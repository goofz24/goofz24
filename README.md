## Projects

- **[Receiving Reader](https://github.com/goofz24/receiving-reader)**: reads supplier packing slips and invoices (PDFs and phone photos, English and Spanish) with the Claude API, checks them against the purchase order and flags the lines a person should look at. On 18 made-up test documents it read 918 of 918 fields correctly. TypeScript, React, Zod.
- **[Bilingual Inquiry Assistant](https://github.com/goofz24/bilingual-inquiry-assistant)**: reads website inquiries in English or Spanish and returns checked JSON (service, budget, urgency, draft reply) using the Claude API. 28 of 29 right on a real accuracy test. TypeScript, Zod.
- **[Receiving & IT Asset Dashboard](https://github.com/goofz24/receiving-dashboard)** ([live demo](https://receiving-dashboard.vercel.app)): stock receiving and IT asset tracking on Postgres (Supabase) and Next.js, with SQL joins, views, a read-only role and row-level security. Made-up data.
- **[MCO WebLab MCP Server](https://github.com/goofz24/mcoweblab-mcp)**: gives Claude tools to price website projects, recommend sizes from a size chart and help with IT support checks. TypeScript, MCP.
- **[MCO Size Chart Theme](https://github.com/goofz24/mco-size-chart-theme)**: a Shopify Dawn theme with a reusable size chart section driven by metaobjects, inches/centimeters switching, English and Spanish text, and GA4 events through Google Tag Manager. Theme Check and automated tests run in GitHub Actions.
